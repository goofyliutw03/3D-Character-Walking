# Requirements Document
## Project Description
使用者目前只能選固定日夜光照，需要在 Time of Day 的 Solar Sport 直接拖曳24小時轉盤、觀察相機相對北向並切換四季太陽軌跡。
## 1. 時間轉盤
1.1 系統應顯示00–23時標及每小時5等分（4根內刻線，12分鐘一格）。
1.2 當使用者以滑鼠或單指拖曳時針／轉盤時，系統應即時更新時間、太陽方向及陰影，跨午夜可循環。
1.3 系統應提供時間欄位及鍵盤方向鍵、Home／End操作，並顯示HH:mm。
## 2. 指北針
2.1 系統應提供水平圓盤N/E/S/W，北固定為世界-Z，東為+X。
2.2 當渲染相機方向改變時，指北針應更新相對方位；正俯視投影退化時應保留最近穩定方向。
## 3. 四季與緯度
3.1 系統應提供春分／夏至／秋分／冬至代表季節及-90至90度緯度，預設北緯25度、春季、12:00。
3.2 當時間、季節或緯度改變時，系統應更新太陽高度、方位及日夜，允許極晝／極夜。
3.3 系統應標明場景太陽時間，非所在地民用時間或精密天文預報。
## 4. 整合與生命週期
4.1 系統應提供預設關閉的Solar Sport開關，既有白天／黃昏／夜晚仍可使用；選擇預設應退出Solar模式。
4.2 當太陽低於地平線時系統應停用太陽直射；夜間應啟動既有路燈與候選陰影設定，背景／霧色應同步。
4.3 系統應拒絕非有限時間／緯度及非法季節且不部分更新；卸載應釋放事件及更新回呼。
4.4 本範圍不新增依賴、外部資產、自動時間播放、真實定位、commit或push；既有人工驗收不概括關閉。
