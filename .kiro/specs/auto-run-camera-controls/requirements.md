# 需求

2026-11-08 [1Y-8] 手機追加授權。自動奔跑第三人稱／魚眼的單指拖曳控制角色轉向與鏡頭俯仰，雙指同向拖曳環繞，雙指張開拉近／捏合拉遠。靜止時保留單指點地／原 Orbit，雙指縮放同樣可以進出第一人稱。第一人稱單指觀看，捏合退出並還原跑停。反向與鏡頭歸位以按鈕操作。多指增減、取消、模式切換、失焦與卸載必須清理，不誤點地面；一指固定的 pinch 也須支援。

使用者核准本 chat 三份規劃，依序自動審閱與實作。

1. 自動奔跑開關沿面向以現有 Run 速度前進，保留碰撞。接管巡迴與點地導航。Stop、關閉與失焦停止或暫停，失焦須明確恢復。
2. 中鍵反向 180° 並繼續奔跑，相機平滑回新方向起始構圖。
3. 模式開啟且第三人稱／魚眼，Ctrl 水平滑鼠位移旋轉相機，無 Ctrl 改角色面向。每段連續手勢半畫布寬對應 180°，上限 180°，200ms 無輸入重設。Ctrl 改變時重設基準。垂直位移調整俯仰。
4. F1 在畫布焦點時歸位水平／俯仰。其他視角保留奔跑及原有滑鼠控制。
5. 外部視角最近使用者距離後，額外向內滾輪切第一人稱並暫停移動。遮擋縮放不觸發。記錄原模式及跑／停，持續向外滾輪回原模式並歸位，僅在仍允許時恢復奔跑。
6. 第一人稱視線限水平 ±80°、向上60°、向下70°。頭燈跟隨最終相機方向。Stop／關閉禁止舊狀態恢復。
7. 畫布外不接觀看輸入，中鍵抑制自動捲動。保留手機、非自動奔跑操作及 reduced motion。
8. 無修飾鍵 Y 在畫布焦點時切換，忽略 repeat／組字，面板與輸入欄位不攔截。與面板共用同一切換方法。

9. 1Y-5：以 Camera 模式分類輸入策略，集中相機行為、DOM 輸入及模式切換流程。保留需求1–8。模式、auto-run、Stop、失焦與Ctrl切換須清除舊手勢及滾輪累積，下一個滑鼠事件重新取得真實Ctrl狀態，避免突轉。

10. 交互審查追加。驗證全部有向視角組合與跑／停／暫停、Follow、轉場打斷、四種遮擋策略。只有畫布焦點可接收特殊滑鼠觀看，重複 F1 須攔截但不重啟過渡。切場景或圖形連線遺失須清除第一人稱回復紀錄。
11. 場景控制契約支援開放、半開放、半封閉、過渡、封閉及水下分類，獨立配置構圖、相機邊界、地面導航及自動奔跑能力。現有城市／洞穴接入，其他類型使用合約測試；新場景的游泳或飛行另依規格。
