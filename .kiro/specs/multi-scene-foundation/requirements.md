# 多場景基礎需求

1. 整合已驗收的 Needle Engine 基準與原始專案的城市建築、自動巡迴、人物編輯。Needle 正常啟動、明示 legacy 模式與啟動失敗回退均須保有同一套 Viewer 功能。
2. 首批可操作交付包含城市與程序化洞穴驗證區。共用角色、表情、鏡頭、粒子、Inspector、渲染及控制面板。道路、太陽和水域等控制依場景能力提供。
3. 場景切換保留角色、畫質與鏡頭偏好，重設位置、速度、導航及瞬時效果。失敗時保有原場景，快速連按只接受最新請求。舊載入結果與場景資源須可釋放。
4. 環境可選用地面、飛行、游泳及零重力移動。角色、目標及相機使用同一場景的碰撞與區域資料。現有平面導航先用於適用的城市地面。
5. GPU 效果共用時間、品質及資源生命週期。影響通行的置換須有同源或誤差有界的碰撞資料。品質及減少動態效果的偏好須維持移動判定。

## 1Y-3 已核准追加頭燈

2026-11-07 補錄本次已核准的實作範圍。Rock Chamber 預設啟用操控角色頭燈，隨頭部位置與角色面向更新，後續封閉場景可依能力契約提供。面板包含開關、距離、FOV、光色、光強度、邊緣柔化及光塵開關／數量／速度。光塵在光錐內隨機分佈、飄動並淡出，容量有上限，減少動態效果時隱藏光塵。場景卸載釋放資源，光塵排除相機遮擋判定。
