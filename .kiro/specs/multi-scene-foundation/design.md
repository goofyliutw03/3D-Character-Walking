# Needle 架構下的多場景設計

## 1Y-3 頭燈追加設計紀錄

2026-11-07 補錄已核准方案的實作設計。Environment 選用 Headlamp 能力，洞穴擁有其資源。光源掛在洞穴 scene 下，與環境遮擋子樹分離；Viewer 在角色位置更新後同步頭燈位置及朝向，城市提供空能力。SpotLight 半角使用 FOV／2，距離 2–18m、FOV 12–85°、強度 0–240cd、柔化 0–1。HeadlampSettings 共用驗證與面板範圍，非法更新整批拒絕。

光塵使用固定 96 顆種子與單一 Points draw，Shader 在光錐和最大距離內產生短路徑及淡入淡出，不建立逐幀粒子物件。面板可調 0–96 顆、0.25–2 倍速度。減少動態效果時隱藏光塵並凍結時鐘。場景釋放 geometry、material 與 light，重新進入洞穴使用預設參數。

以下保留原多場景設計。

以 `0e28a64` 的 Needle 5.1.16 為整合來源。原始專案以 `2825627` 為共同基底，另有已交付但未提交的巡迴、建築與角色編輯。共用檔案依序整合。合併 ViewerApp 時保留兩邊的初始化、更新與釋放順序，Vite 同時保留兩邊的既有設定。

沿用一個 Three.js Scene 作為長存的 Needle Context 根與一個 WebGL2 renderer。Needle 預設路徑透過 Context 的 composer 執行自訂渲染通道，包含水景、魚眼、X-ray 與最後的鏡頭水滴。既有 Shader 與深度取樣維持相同順序，legacy 回退共用效果。場景切換替換環境子樹與世界查詢，角色和相機留在 Viewer 層。Needle Behaviour 與 legacy loop 共用同一 tick。切換以版本序號隔離晚到結果，準備成功後於單一提交點換綁定。切換失敗或 Context 遺失時取消待處理請求。

每個場景提供出生點、移動策略、碰撞、導航與可選功能。切換時重新綁定相機遮擋、目標、Inspector 與光源，清除輸入及跨場景暫態。程序化 Shader 在既有 Three.js 多通道渲染中運作，並按效果同步陰影深度材質、法線與裁切範圍。

| 環境 | 效果與行為 | 主要驗證 |
|---|---|---|
| 自然地表驗證區 | 高度圖置換、草木風動，作為洞穴入口及空中地表的共用能力 | 高度取樣與碰撞、點選及陰影一致 |
| 地下洞穴 | 岩壁與鐘乳石噪聲置換、滴水、局部燈。地質變動先作視覺試驗 | 岩壁／洞頂及鏡頭碰撞。可通行崩塌另需同步更新導航和碰撞 |
| 空中飛行 | 天空穹頂、網格雲位移、與太陽方向相連的天空材質 | 升降、追蹤、邊界及天空日照一致 |
| 海下／池下／地下水道 | Gerstner 波、水流擺動、氣泡，搭配片段階段的霧與焦散。水道含乾地與濕區 | 共用波參數與時鐘，水平位移納入水面取樣誤差。相機／角色進出有各自緩衝 |
| 太空 | 星場、軌道粒子、實例隕石、行星置換與材質條紋 | 慣性、煞車、姿態、碰撞與 LOD。可互動隕石有獨立碰撞代理 |

驗證包括桌面及行動尺寸、Needle 及 legacy、載入失敗／切換競爭／重複切換、Context 遺失及恢復、既有水景／魚眼／X-ray／巡迴／角色編輯。以實測決定 GPU 粒子與網格預算。回復點採已驗收 Needle Release，城市維持預設入口。
