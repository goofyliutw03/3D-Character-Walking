# 需求
- R1：目前使用者登入後背景啟動人物系統匣圖示，不顯示命令視窗、不開瀏覽器。
- R2：選單 Browsing / Restart / Exit；瀏覽使用預設瀏覽器，Exit 保留自啟。
- R3：防重複啟動，port 衝突不停止他人服務；只清理自有程序。
- R4：可安裝／移除自啟、文件化 rollback，既有 preview 與防火牆不動。
## TRAY-02／dist 自動更新

- 發佈應在 tests、build 與既有 Release 同步成功後，以原子方式公開差異包。每包記載基準版、目標版、台北 Release 日期、檔案 SHA-256 與移除清單。
- 控制器啟動時及其後每 60 秒檢查，按照版本順序套用。基準、內容或雜湊驗證失敗時，應維持目前服務。
- 驗證完成才停止自有 Node 子程序。啟動新版並確認 loopback 實際回傳新版內容後才持久化與清理。啟動或健康檢查失敗時應復原前版。
- 歷程應記錄時間、版本、逐檔新增／替換／移除與切換各步驟。通過健康檢查及持久化後才顯示含版本及日期的成功通知。
