# 有限水池需求

1. Environment 提供有限水池，桌面與觸控可在水中升降。移動包含浮力、水阻、水深及有限速度，並支援所有既有角色膠囊。
2. 水面、池底、池壁和池緣以同一場景資料定義。任意正常移動皆依完整膠囊掃掠限制，低幀率及最高速度不可穿透。
3. 只有指定池緣能執行攀出。垂直及水平路徑與乾地站立點皆須通過淨空檢查。走入池內會從地面移動轉入游泳。
4. 視覺水面、角色取樣及相機使用同一權威水位與場景時鐘。相機依自己的位置判定是否在水中。
5. 驗證合法／非法定位、邊界接觸、各角色尺寸、低幀率、切換失敗、Needle／legacy 和既有場景。海域、地下水道及太空留後批。

依 1Y-16 授權完成 inline 審閱。條件涵蓋原場景規範的水池條目及場景切換契約。
