# 各場景運行、碰撞與活動範圍設計規範

版本 v0.1，2026-11-10。使用者已確認設計方向並核准第一批共用 World Query／Range Policy 與城市相容適配；分批規格與實際能力見 [.kiro/specs/world-query-range-policy](../.kiro/specs/world-query-range-policy/)。第二批地表／洞穴已於1Y-14核准，實際能力與驗證見[ground-volume-world-query](../.kiro/specs/ground-volume-world-query/)。有限盒直立膠囊及高度場支撐不等同任意網格物理；飛行／水域／太空仍另批確認。

## 1. 範圍與基線

涵蓋城市、自然地表、地下洞穴、空中飛行、海下／池下／地下水道、宇宙漂浮。目的為共用角色、鏡頭、表情、粒子、光照、Inspector、控制面板及場景生命週期。

現有 Environment／SceneSwitch 已有城市、洞穴及地表入口。1Y-13城市使用planar World Query；1Y-14地表／洞穴增加有限盒直立膠囊、同源地表支撐與多層查詢，WalkableWorld保留相容欄位。任意網格三維膠囊、通用體積聯集及飛行／游泳／零重力控制仍為後續擴充。

複雜度 ARCHITECTURE，建議高能力模型與高推理。確認後按共用契約、地面場景、三維環境依序交付，實際實作分項記錄驗證結果。

## 2. 共用運行架構

| 層級 | 責任與資料 |
|---|---|
| Needle Runtime | 唯一更新入口、Context、相機及 composer，自訂水景／魚眼／X-ray 通道 |
| 場景管理 | prepare、validate、activate、deactivate、dispose 與非同步請求版本 |
| Scene Definition | 穩定場景 ID、版本、座標、出生點、能力、資源及區域描述 |
| World Query | sweep、overlap、raycast、surfaceSample、regionSample，共用權威座標 |
| Motion Strategy | ground、flight、swim、zeroGravity，輸出位置、姿態、速度及接觸狀態 |
| Range Policy | 活動範圍、禁入區、警戒帶、跨區轉換及復原策略 |
| Presentation | 動畫、Shader、光照、音效擴充點、UI 與 debug 顯示，讀取解算結果 |

座標以公尺、Y-up 及秒為單位。初期在有限世界座標內運行，行星引力與跨天文尺度原點重定位另設規格。

每次模擬步驟依序執行輸入／控制權判定、取樣環境力、積分候選位移、掃掠實體與範圍邊界、滑動／接地、提交權威狀態、區域轉換事件。之後更新角色動畫、相機、效果及渲染。角色同一時刻由一個移動策略提交位置。

建議模擬固定 1/60 秒，每畫面最多四個子步驟。剩餘過量時間採有界丟棄並記錄，返回背景時清空累積器。GPU 視覺插值不回寫物理位置。既有角色速度及手勢行為以回歸驗證維持。

## 3. 碰撞規則

### 3.1 形狀與查詢

- 角色採膠囊，尺寸來自角色碰撞設定，模型縮放與膠囊更新需一起驗證。地面採直立膠囊，游泳及飛行初期也使用直立膠囊以降低姿態穿模的不確定性。全姿態碰撞後續另驗。
- 靜態場景採簡化盒、凸體、地形高度場或三角面碰撞代理。高度場只表示單值地表，多層洞穴採三維表面資料。
- 位移使用膠囊 swept query，寬相位先查空間索引，再取最近接觸。有限次滑動迭代，失去可行位移時停止，保留最後有效位置。
- 大位移、傳送及編輯位置使用完整 overlap 與範圍驗證。資料含 NaN、無效尺度或查詢未載入時原子拒絕。
- 建議初始 skin 為 0.02m、接觸迭代上限四次、最大步高 0.25m、最大可步行坡角 45°。皆為待實測設定值，步高需同時檢查頭部空間。

### 3.2 查詢層

| 層 | 角色阻擋 | 相機阻擋 | 導航／互動 |
|---|---|---|---|
| SolidEnvironment | 是 | 依場景遮擋策略 | 地面與障礙來源 |
| DynamicActor／Vehicle | 指定配對啟用 | 預設排除 | 有界避讓或停等 |
| WalkableSurface | 接地及坡度判定 | 視幾何厚度 | 可點選目的地 |
| WaterVolume／RegionTrigger | 區域事件 | 水下效果判定 | 移動模式與環境取樣 |
| Boundary | 是，另含軟限制 | 依獨立相機範圍 | 阻止無效目的地 |
| Decoration／Particle | 預設排除 | 預設排除 | 需要互動時另設代理 |

X-ray 的可視遮擋分類與物理碰撞分類分開配置。例如透明玻璃仍可阻擋角色，水域觸發體也可產生區域事件。

### 3.3 動態物件

初期採權威角色控制器與運動學障礙。角色、NPC 及車輛碰撞配對須明列，現有車流停讓邏輯於整合前保留。若加入剛體引擎，由適配層提供相同 World Query，避免角色同時被兩套求解器推動。可移動平台須提供表面速度。

## 4. 活動範圍遮罩

### 4.1 定義

「活動範圍遮罩」在本草案解讀為角色可活動的幾何／語意區域。UI 可另外顯示這份資料。螢幕遮罩、霧、相機裁切及 Shader discard 不參與通行判定。

每個 region 包含 id、revision、幾何、適用角色／模式、允許或禁止、優先序、邊界行為、環境參數及 debug 樣式。安全出生點與復原點須帶場景版本。

- 地面可用多邊形含洞及表面 ID，搭配高度／淨空限制。
- 空中、水下與太空用三維盒、球、凸體或有界體積組合。
- 可活動區域先取允許區聯集，再扣除禁入區，最後與實體淨空及模式能力取交集。若無任何允許區資料，預設拒絕移動。
- 實體禁入優先於允許。角色專屬規則先解析成確定結果。環境參數以顯式 priority 決定，同優先序再以穩定 id 排序，載入時提示衝突。
- 使用膠囊完整體積判斷範圍，將角色半徑與高度納入安全距離。窄通道尺寸不足時視為不可通行。

### 4.2 邊界行為

| 類型 | 行為 |
|---|---|
| 警戒帶 | 顯示邊界／提示，可調減速，不直接傳送 |
| 硬邊界 | 掃掠至接觸處，去除朝外速度，保留切向移動 |
| 轉換邊界 | 目標區域已準備且入口淨空有效時提交模式／場景切換 |
| 危險區 | 明列掉落、重生或撤回規則，初期採安全點復原 |
| 資料缺口 | 停在已載入區，顯示載入／失敗狀態 |

建議警戒帶為地面 1m、飛行及水下 3m、太空以速度與煞停距離動態設定。高速移動必須滿足有效偵測距離涵蓋反應與煞停距離。安全上限需由場景尺度和最高速度驗證。

區域進出採空間 hysteresis，建議水面門檻上下各 0.1m。角色與相機分開取樣，避免角色在水下而相機在水上的效果判定錯誤。模式轉換保留合法速度分量並明確重設其他狀態。

### 4.3 遮罩與其他系統

角色手動操作、自動奔跑、點地導航、巡迴、XYZ 編輯與出生復原共用 Range Policy。導航先建於可行走遮罩，執行中仍逐步碰撞驗證。相機使用獨立範圍，第三人稱可超出角色範圍但須留在已載入安全區。

Inspector debug 可顯示允許區綠色、禁入區紅色、警戒帶黃色、轉換入口藍色，含 region id 與作用模式。一般觀看預設關閉，不以色彩作唯一辨識。

## 5. 各場景規格

| 場景 | 運行與移動 | 碰撞 | 活動範圍與轉換 |
|---|---|---|---|
| 城市 | ground，保留 NPC、交通與巡迴 | 路面／人行道、建築代理、角色／車輛指定配對 | 可走路網扣建築及池岸，外圈硬邊界，過街由號誌／交通政策決定 |
| 自然地表 | ground，高度場置換、植被風動 | GPU／CPU 共用量化樣本與三角切分，坡度、步高與樹幹代理 | 分塊可走多邊形，扣陡坡／水域／未載入分塊，懸崖採明列危險規則 |
| 地下洞穴 | ground，可接地下湖與局部光源 | 三維岩壁、洞頂、柱及多層表面，禁止僅以單一 XZ 高度判定 | 三維通道與表面 ID，扣洞頂淨空不足區、裂縫及封閉岩體。入口有明確 portal |
| 空中飛行 | flight，加速／阻力／升降，初期保持地平線穩定 | 掃掠山體／建築，雲預設視覺區域 | 有限飛行體積，地板／高度上限、邊界減速及硬限制，著陸前驗證坡面與淨空 |
| 海面下 | swim，浮力、阻力、水流與水深 | 海床、礁石、實體設施，水面為轉換區 | 海域體積扣岩體，海床／最大深度／水平外圈限制，水面可切至漂浮狀態 |
| 水池下 | swim，沿用水域系統並限制波幅 | 池底、池壁與池緣，完整三維淨空 | 有限水體，出水僅在明列可攀出或離水入口，禁止直接穿池壁 |
| 地下水道 | ground／swim 分區，水流沿通道設定 | 管壁、閘門、橋與乾地平台 | 相連水域與乾地表面，優先序解決重疊，轉換前檢查站立空間，狹窄段可禁游 |
| 宇宙漂浮 | zeroGravity，慣性、推進與主動煞車 | 膠囊掃掠設施／可互動隕石，固定星場排除 | 有限任務體積及禁入球／盒，外圈先提示與限制推進，再清除朝外速度。初期不反彈 |

空中及太空的六自由度翻滾、海洋呼吸／傷害、地震撕裂與可破壞地形需另外定義玩法及驗收，再接入共用契約。

## 6. Shader 與碰撞一致性

靜態地形共用樣本、座標轉換、插值與三角切分。品質變更優先改視覺細節，權威地形保持穩定，必要更換時先驗證現有角色位置。

岩壁置換若只作細節，幅度必須被碰撞代理的誤差預算涵蓋。影響通行的大變形須同步提交幾何、碰撞、導航與遮罩 revision，提交前沿用舊版本。

Gerstner 波需提供 CPU 表面查詢並使用同一時鐘。含水平位移的水面須處理反解與明列誤差界。水域觸發、浮力與水下鏡頭各自取樣，減少動態效果時以一致策略維持物理。

深度陰影、主渲染、點選及相機遮擋使用相容的變形／代理。視覺 LOD 不能隱藏仍有效的邊界。粒子可視效果只有在另設碰撞代理後才參與交互。

## 7. 場景切換與復原

prepare 後驗證碰撞、遮罩、能力與安全出生點。原場景在新場景可提交前保持運作。提交時統一替換查詢、角色策略、相機與 UI。bind 失敗須回復原場景綁定，成功後才釋放舊場景。快速切換只提交最新版本。

Context 遺失時停止物理與切換提交，清空暫態。恢復先重建 GPU 資源，再驗證 CPU 權威狀態後續作。安全點失效時依序尋找同場景最近有效點、預設出生點，全部失效則顯示錯誤並停止操作。

## 8. 驗收與交付順序

1. 共用 World Query／Range Policy 契約與城市相容適配，先驗證輸入、導航、巡迴、編輯位置共用限制。
2. 地表驗證高度及三角切分、坡面／邊緣、跳躍及陰影。洞穴驗證多層、洞頂、斜向滑動、窄通道及相機。
3. 飛行驗證高速掃掠、上下邊界及著陸，水域驗證浮力、水面進出、池壁、乾濕交界。
4. 太空驗證慣性煞停、有限活動體積及高速障礙，完成跨場景往返與失敗復原。

各項均測正常／非法資料、最大速度、低幀率、多次切換、不同角色尺寸及 Needle／legacy。正好接觸邊界的測試採明列容差。性能門檻使用指定裝置量測，記錄碰撞耗時、候選數、draw calls、記憶體與切換後資源數，不以軟體渲染樣本推定手機性能。

## 9. 提請確認

- 活動範圍採權威幾何／語意區域，另提供 debug 視覺遮罩。
- 初期採運動學膠囊與查詢適配，剛體需求另行選型並核對現有 Needle 版本與授權。
- 地面保留步跑跳，飛行與水下先保持地平線，太空先做有限空間與煞車。
- 超界採警戒、硬限制與必要安全點復原。傷害、反彈及無限世界另列玩法需求。
- 先確認本規範，再實作新增的三維碰撞及範圍遮罩契約。既有成果與缺口依實際驗證記錄。

本文件為分批設計方向；1Y-13／1Y-14運行變更與驗證以各批spec為準，非全表均已實作。token 用量無法取得精確值，缺少官方起訖基準。
